              HOW TO START/STOP BOTS IN TMUX
═══════════════════════════════════════════════════════════════

📋 QUICK COMMANDS (Copy-Paste Ready)
═══════════════════════════════════════════════════════════════

🚀 START ALL BOTS:
bash /Users/shailendrasinghrajawat/Documents/WorkingBot/scripts/start_tmux_daemon.sh

🛑 STOP ALL BOTS:
/opt/homebrew/bin/tmux -S ~/.tmux-gridbot/default kill-session -t gridbot

📺 VIEW BOTS (Attach to tmux):
/opt/homebrew/bin/tmux -S ~/.tmux-gridbot/default attach -t gridbot

🔍 CHECK STATUS:
/opt/homebrew/bin/tmux -S ~/.tmux-gridbot/default has-session -t gridbot && echo "✅ Running" || echo "❌ Not running"

═══════════════════════════════════════════════════════════════
              TMUX KEYBOARD SHORTCUTS
═══════════════════════════════════════════════════════════════

⌨️  DETACH (Exit without stopping bots):
    1. Press: Ctrl+B (then release)
    2. Press: d
    → Bots keep running in background

💡 OR just close Terminal window - bots stay alive!

🔄 SWITCH BETWEEN PANES (when attached):
    1. Press: Ctrl+B (then release)
    2. Press: Arrow keys (←↑→↓)

📜 SCROLL UP (view history):
    1. Press: Ctrl+B (then release)
    2. Press: [
    3. Use Arrow keys or Page Up/Down
    4. Press: q (to exit scroll mode)

═══════════════════════════════════════════════════════════════
              TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

❓ "Session already exists" when starting:
   → Bots are already running! Use attach command to view them.

❓ Pane shows "bash" instead of Python:
   → That bot finished/crashed. Check logs in logs/ folder.

❓ Can't see tmux session after starting:
   → Wait 2-3 seconds for bots to initialize
   → Run status check command

❓ ModuleNotFoundError when bots start:
   → Check PYTHONPATH is set (daemon script does this)
   → Script location: scripts/start_tmux_daemon.sh

═══════════════════════════════════════════════════════════════
              DAILY WORKFLOW
═══════════════════════════════════════════════════════════════

🌅 MORNING (Start trading):
   1. Open Terminal
   2. Paste: bash /Users/.../start_tmux_daemon.sh
   3. Wait for "✅ tmux session created successfully!"
   4. Optional: Attach to view bots
   5. Detach (Ctrl+B, d) or close Terminal

🌙 EVENING (Stop trading):
   1. Open Terminal
   2. Paste: /opt/homebrew/bin/tmux -S ~/.tmux-gridbot/default kill-session -t gridbot
   3. Confirm with status check

📊 MONITORING:
   • WebUI: http://localhost:5555 (always available)
   • Attach to tmux: See live bot output
   • Check logs: tail -f logs/bot_live.log
