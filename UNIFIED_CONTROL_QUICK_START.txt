┌────────────────────────────────────────────────────────────────────┐
│ 🛡️ WHAT GETS STARTED                                              │
└────────────────────────────────────────────────────────────────────┘

  When you run: ./scripts/unified_bot_control.sh start
  
  System does:
    1. 🧹 Cleans stale lock files
    2. 🚀 Starts threaded bot via PM2
    3. ⏳ Waits 10 seconds for initialization
    4. 📊 Starts shadow mode (24h comparison)
    5. ✅ Shows status of both systems
  
  Threaded Bot (PRIMARY):
    ✅ Places all orders
    ✅ Updates runtime_state.json
    ✅ Managed by PM2 (auto-restart)
    ✅ Reads config from WebUI
  
  Shadow Mode (OBSERVER):
    ✅ Reads runtime_state.json
    ✅ Runs async calculations
    ✅ Compares results every 60s
    ✅ Logs discrepancies
    ❌ Never places orders
