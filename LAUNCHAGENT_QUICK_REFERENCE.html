📋 Service Management Commands

Basic Control 


Start service
launchctl start com.gridbot.webui

Stop service launchctl stop com.gridbot.webui

Restart service launchctl stop com.gridbot.webui && launchctl start com.gridbot.webui

Check status launchctl list | grep gridbot

Service Lifecycle 


Unload service (remove from system)
launchctl unload ~/Library/LaunchAgents/com.gridbot.webui.plist

Load service (add to system) launchctl load ~/Library/LaunchAgents/com.gridbot.webui.plist

Reload after plist changes launchctl unload ~/Library/LaunchAgents/com.gridbot.webui.plist launchctl load ~/Library/LaunchAgents/com.gridbot.webui.plist

🔄 Update Workflow

When You Need to Update Code:

Step 1: Stop Service 

launchctl stop com.gridbot.webui
Step 2: Edit in Cursor
  • Open Cursor
  • Make your changes
  • Test: `python3 webui/backend/app.py`
  • Commit: `git add . && git commit -m "your changes"`
Step 3: Restart Service 

launchctl start com.gridbot.webui
Done! ✅ ---

🛠️ Troubleshooting

Service Not Starting 


Check logs
cat logs/launchagent_webui_error.log

Check service status launchctl list | grep gridbot

Restart service launchctl stop com.gridbot.webui launchctl start com.gridbot.webui

WebUI Not Accessible 


Test API
curl http://localhost:5555/api/health

Check if port is in use lsof -i :5555

Kill conflicting process kill -9 $(lsof -t -i :5555)

Permission Issues 


Fix file permissions
chmod +x webui/backend/app.py

Check Python path which python3

Environment Variables Add to plist under `EnvironmentVariables`: 

YOUR_VAR
your_value

Resource Limits Modify in plist:

    NumberOfFiles
    1024
