  📊 ARCHITECTURE OVERVIEW
================================================================================

Delta Exchange APIs → Collector → SQLite → Flask API → React Chart
     (every 30s)       (Python)   (Fast)    (REST+WS)   (Recharts)
                                                            ↓
                                                      Dashboard UI

Data Flow:
1. Collector polls Delta Exchange every 30 seconds
2. Fetches IV from options (mark_iv from ATM strikes)
3. Calculates RV from candles (σ * sqrt(252) * 100)
4. Stores in SQLite (iv_snapshots, rv_calculations)
5. Flask API serves data via REST endpoints
6. WebSocket pushes real-time updates
7. React component renders professional chart
8. Auto-refreshes every 30 seconds
