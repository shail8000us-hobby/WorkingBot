DEPENDENCY INJECTION PATTERN (Use Everywhere)
=============================================================================

ALL modules must use dependency injection. NO global state.

Example Pattern:

```python
# gridbot.py (Main Orchestrator)

class GridBot:
    def __init__(self, config, api_client):
        
        # 1. Initialize pure logic first (no dependencies)
        self.grid_calc = GridCalculator(
            config=config
        )
        
        # 2. Initialize state manager (needs lock)
        self._state_lock = threading.Lock()
        self.position_mgr = PositionManager(
            config=config,
            state_lock=self._state_lock,
            grid_calc=self.grid_calc
        )
        
        # 3. Initialize order manager (needs API + position state)
        self.order_mgr = OrderManager(
            api_client=api_client,
            grid_calc=self.grid_calc,
            position_mgr=self.position_mgr
        )
        
        # 4. Initialize fill detector (needs positions + orders)
        self.fill_detector = FillDetector(
            websocket=self.ws_manager,
            position_mgr=self.position_mgr,
            order_mgr=self.order_mgr
        )
        
        # 5. Initialize reconciliation (needs API + positions)
        self.reconciler = Reconciliation(
            api_client=api_client,
            position_mgr=self.position_mgr,
            order_mgr=self.order_mgr
        )
        
        # 6. Initialize volatility handler (needs everything!)
        self.volatility = VolatilityHandler(
            config=config,
            grid_calc=self.grid_calc,
            position_mgr=self.position_mgr,
            order_mgr=self.order_mgr,
            reconciler=self.reconciler
        )
        
        # 7. Initialize WebSocket handler (routes to modules)
        self.ws_handler = WebSocketHandler(
            fill_detector=self.fill_detector,
            position_mgr=self.position_mgr,
            volatility=self.volatility
        )
```

Key Principles:
- Dependencies flow in ONE direction (no circular!)
- Pure logic (GridCalculator) has zero dependencies
- State manager (PositionManager) owns the lock
- Other modules receive dependencies via constructor
- GridBot is THIN - just wires modules together

MODULE COMMUNICATION RULES
=============================================================================

1. COMMAND FLOW (GridBot → Modules)
   GridBot.run() 
     → order_mgr.place_buy()
     → fill_detector.process_fill()
     → position_mgr.add_position()

2. EVENT FLOW (Modules → GridBot via Callbacks)
   fill_detector.on_fill_detected 
     → calls callback(fill_data)
     → GridBot handles event
     → delegates to order_mgr.place_tp()

3. STATE ACCESS (Always via PositionManager)
   ❌ WRONG:
   order_mgr.open_tranches.append(position)
   
   ✅ CORRECT:
   position_mgr.add_position(position)

4. THREAD SAFETY (Lock Ownership)
   - PositionManager OWNS _state_lock
   - Other modules REQUEST lock from PositionManager
   - Pattern:
     ```python
     with position_mgr.state_lock:
         positions = position_mgr.get_positions()
     ```

5. NO CIRCULAR DEPENDENCIES
   ✅ Allowed:
   order_mgr → position_mgr (uses state)
   fill_detector → position_mgr (updates state)
   
   ❌ Forbidden:
   position_mgr → order_mgr (circular!)
   Use callbacks instead.
