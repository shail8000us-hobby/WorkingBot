HOW IT WORKS
═══════════════════════════════════════════════════════════════════════

AUTOMATIC POSITION TRACKING:

1. When BUY order fills:
   → Bot creates position in tracker
   → Records entry price, size, TP order ID
   → Calculates liquidation price
   → Saves to positions.json

2. Every 10 seconds (heartbeat):
   → Bot updates all positions with current price
   → Recalculates PnL for each position
   → Updates distance to liquidation
   → Shows compact summary in logs

3. Every 5 minutes (health check):
   → Displays full position table
   → Shows liquidation prices
   → Color-coded risk levels
   → Logs PnL snapshot to CSV
   → Checks for liquidation alerts
   → Attempts margin top-up if needed

4. When TP order fills:
   → Bot closes position in tracker
   → Records final PnL
   → Removes from positions.json

═══════════════════════════════════════════════════════════════════════
DELTA EXCHANGE LIQUIDATION FORMULA
═══════════════════════════════════════════════════════════════════════

For LONG positions (bot only trades long):

  Liquidation Price = Entry Price × (1 - Maintenance Margin %)

Example:
  Entry Price: ₹120,000
  Maintenance Margin: 2.5% (typical for BTC on Delta)
  Liquidation Price = 120,000 × (1 - 0.025) = ₹117,000

If price drops to ₹117,000, position will be liquidated.

RISK LEVELS
═══════════════════════════════════════════════════════════════════════

🟢 SAFE (Margin > 80%)
   - Normal operation
   - No action needed

🟡 WARNING (Margin 50-80%)
   - Monitor closely
   - Telegram alert sent
   - Auto top-up enabled

🟠 DANGER (Margin 20-50%)
   - Risky situation
   - Urgent Telegram alert
   - Auto top-up triggered
   - Consider manual intervention

🔴 CRITICAL (Margin < 20%)
   - Liquidation imminent
   - Emergency alert
   - Auto top-up attempted
   - Manual action required

═══════════════════════════════════════════════════════════════════════
AUTO MARGIN TOP-UP
═══════════════════════════════════════════════════════════════════════

How it works:
1. Triggers when margin drops below 60%
2. Calculates amount needed to reach 90% safety
3. Checks available balance
4. Reserves 20% of balance (safety reserve)
5. Caps top-up at 50% of available balance
6. Maximum 3 top-ups per position
7. Sends Telegram notification

Safety limits:
- Won't use reserve balance
- Won't exceed 50% of available
- Max 3 attempts per position
- Logs all actions

CSV LOG FORMAT
═══════════════════════════════════════════════════════════════════════

File: bot/reports/pnl_history_YYYYMMDD.csv

Columns:
- timestamp: ISO format datetime
- open_positions: Number of open positions
- total_pnl_usd: Total PnL in USD
- total_pnl_inr: Total PnL in INR
- risk_percent: % of MAX_ACCOUNT_LOSS_INR used
- avg_margin_ratio: Average margin ratio across positions
- min_margin_ratio: Minimum (worst) margin ratio
- positions_at_risk: Count of positions at risk
- overall_liq_risk: low/medium/high/critical
- status: safe/warning/danger/critical

Example:
2025-10-11 10:00:00,3,-20.00,-1700.00,17.00,0.8400,0.7200,1,low,safe
