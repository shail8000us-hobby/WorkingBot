📝 HOW TO USE

1. START tmux session (from terminal):
   
   ./scripts/start_tmux_daemon.sh
   
   ✅ Creates session with 3 panes (Guardian, Monitor, Trading)

2. VIEW in WebUI:
   
   http://localhost:5555 → "tmux Professional Setup"
   
   ✅ Shows: "Session active" + attach command

3. ATTACH to view bots:
   
   tmux -S ~/.tmux-gridbot/default attach -t gridbot
   
   Detach (keep running): Ctrl+B then D

4. STOP from WebUI:
   
   Click "STOP SESSION" button
   
   ✅ Works from WebUI!
